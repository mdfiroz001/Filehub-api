

## FileHub v1 polished upgrade
- Responsive premium home hero with quick navigation cards for Files, HTML Templates, AI Prompts and Assistant.
- AI Assistant quick actions for common questions.
- Library search, newest/popular/A–Z sorting and friendly empty states.
- Local favorites, recently viewed items and download history for a faster personal experience.
- Template cards also support favorites; existing unlock, copy and Open Graph flows remain intact.
- PWA support through `manifest.json` and `sw.js` for installable app shell and offline fallback.
- Admin dashboard now includes published template analytics alongside existing file/user metrics.

All personal preference history is stored locally in the browser; no new Firebase schema is required for these v1 features.
